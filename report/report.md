### bitXor

```c
        return (~(~x&~y))&(~(x&y));

```
这道题并不复杂，就是“非二者同为0且非二者同为1”，我只是从中感受到了~按位取反和&按位与可以不假思索地去当作！和&&使用，只是对位操作而已，某种角度上像不假思索的写递归一样，直接就实现了正确答案

### logtwo

```c
int logtwo(int v) {
    int shift=0;
    int result=0;

    shift=(v>0xFFFF)<<4;
    result=result|shift;
    v=v>>shift;
    shift=(v>0xFF)<<3;
    result=result|shift;
    v=v>>shift;
    shift=(v>0xF)<<2;
    result=result|shift;
    v=v>>shift;
    shift=(v>0x3)<<1;
    result=result|shift;
    v=v>>shift;
    shift=(v>0x1);
    result=result|shift;        
    
    return result;
}
```
这道题一方面和后面的leftbitcount一样，因为不能用循环就用了二分的方法，去找最高的1在第几位，一方面。因为所有数都能用2的各个次幂选取并求和来表示，保证了算法正确性；另一方面，因为shift只能由=有一位是1，所以反而用result|shift这一或运算实现了加法；而且shift是1自然左移得到对应2的次幂，为0左移后仍为0也很漂亮

### logicalshift

```c
int logicalShift(int x, int n) {
    return x>>n&~(((1<<31)>>n)<<1);
    //return x>>n&~(~0<<(32-n));
    //return x>>n&~((1 << (32 - n)) + ~0);
}
```
这道题关键就是算术右移后前面会补符号位，因此要把左起n位和全0与一次，关键就成了构造左起n位全0其他位全1的字串，把1移至最左再右移对应位可天然地再左边全部补上1，非常精妙，是正确结果。我注释的第二三个方法也可，但会在n==0时失效，因此有样例没通过。
